# IBM SPSS Modeler - Practical 1

## 📌 Overview
This repository contains the practical work demonstrating how to use the **IBM SPSS Modeler** user interface to create, edit, modify, and save data streams[span_8](start_span)[span_8](end_span).

## 🎯 Outcomes & Learning
* Understand the IBM SPSS Modeler user interface[span_9](start_span)[span_9](end_span).
* Learn how to create and modify streams by connecting different nodes[span_10](start_span)[span_10](end_span).
* Generate outputs, add comments, and configure table outputs with Select nodes[span_11](start_span)[span_11](end_span).

## 🛠️ Required Tool
* **IBM SPSS Modeler 18.0**[span_12](start_span)[span_12](end_span)

## 📋 Tasks & Steps
### Task 1: Setting up IBM SPSS Modeler
1. Open IBM SPSS Modeler from the Start menu[span_13](start_span)[span_13](end_span).
2. Close the Welcome dialog box[span_14](start_span)[span_14](end_span).
3. Navigate to **File > Set Directory** and set the required working folder path (e.g., `SPSS_DEMO\Data Set PA\0A007`)[span_15](start_span)[span_15](end_span).
